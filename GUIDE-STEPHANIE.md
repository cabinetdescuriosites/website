# Ajouter une trouvaille — guide express ✨

*Ajouter un objet prend moins de 2 minutes, promis.*

## Les 5 étapes

1. **Ouvrir l'admin** : `votresite.fr/admin/` → se connecter avec son email.
2. Cliquer sur **« + Trouvaille »**.
3. Remplir la fiche :
   - **Nom de l'objet** — ex. *Vase à glaçure craquelée*
   - **Prix** — juste le chiffre, ex. `85`
   - **Catégorie** — choisir dans la liste
   - **Photos** — glisser-déposer depuis le téléphone ou l'ordinateur (la 1ʳᵉ photo = celle de la galerie)
   - **Description** — 2 ou 3 phrases qui racontent l'objet
   - État / Dimensions / Époque — si on les connaît (optionnel)
   - **Date d'ajout** — cliquer sur **« Maintenant »**
4. Cliquer sur **« Publier »**.
5. C'est tout ! Le produit apparaît sur le site en 1 à 2 minutes. ☕

## Quand une pièce est vendue

Ouvrir la fiche → **Statut** → choisir **« Vendu »** → **Publier**.
Elle reste visible dans la galerie, prix barré (la preuve que ça part vite 😉).
**« Réservé »** fonctionne pareil, pour une pièce mise de côté.

## Bon à savoir

- Modifier un produit : cliquer dessus dans la liste, changer, re-**Publier**.
- Supprimer : ouvrir la fiche → menu « Publier » → supprimer l'entrée.
- Rien n'est visible sur le site tant qu'on n'a pas cliqué **Publier**.
